# ClassIn 15s — 1인 원장 편 (Remotion)

대본: [SCRIPT.md](./SCRIPT.md) · 타이밍 원본: `src/script.ts`

```bash
cd video
npm install
npm run studio     # 브라우저에서 미리보기 / 타임라인 확인
npm run animatic   # out/animatic.mp4 (타이밍 확인용 애니매틱)
npm run typecheck
```

- 폰트는 `public/fonts`에 직접 포함되어 있어 렌더 시 외부 폰트 CDN에 의존하지 않습니다.
- Remotion은 직원 4인 이상 회사가 상업적으로 쓰면 컴퍼니 라이선스가 필요합니다: https://remotion.dev/license
