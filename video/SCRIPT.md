# ClassIn 20초 커머셜 — 1인 원장 편 (질문·공감형 스토리텔링 · 라이트 테마)

> 시네마틱 · 커머셜 · 키네틱 타이포그래피
> 카피와 타이밍 원본은 `src/script.ts`입니다. 카피를 고칠 땐 그 파일만 바꾸면 영상에 그대로 반영됩니다.

| 항목 | 값 |
|---|---|
| 길이 | 20.0초 (600프레임) |
| 규격 | 1920×1080, 30fps, H.264 |
| 템포 | 90 BPM, 1박 = 0.67초 = 20프레임, 모든 컷이 박자에 떨어짐 (30박) |
| 내레이션 | 없음. 텍스트만으로 전달 (SNS 무음 자동재생 대응) |
| 사운드 | 오리지널 BGM + 효과음 105큐, -14 LUFS / -1 dBTP (아래 6장) |
| 렌더 | `npm run render` → `out/classin-20s.mp4` |

15초 버전과 구성(13샷, 5막)은 같고, 템포를 120 → 90 BPM으로 늦춰 각 컷이 1.33배 길어졌습니다. 늘어난 시간은 주로 문장을 읽고 머무는 시간에 쓰고, 등장 모션도 조금씩 느리게 다듬었습니다. 15초 버전은 git 기록(커밋 `89b7f22`)에 남아 있습니다.

## 5. 디자인 — 라이트 테마

- **바탕:** 종이 톤 화이트(#F7F8F4) + 흐르는 도트 그리드 + 부드러운 컬러 필드 + 필름 그레인 + 옅은 비네팅
- **색 온도로 이야기하기:** S01~S03(전)은 지친 회색(#E7EBE8), S04 히트 순간 밝은 종이 톤 + 초록 필드로 전환, AI 구간은 시안·블루 쪽으로 기울었다가 엔딩에서 다시 초록
- **컬러 역할:** 잉크 #0B1410 = 정보 / 레드 #E5484D = 문제 / 그린 #0F8A5E·#10B981 = ClassIn·해결 / 그린→시안→블루 그라디언트 = AI
- **타입:** Pretendard Variable(굵기 45~920을 프레임 단위로 모프), JetBrains Mono(시계·타임코드·지표)
- **UI 카드:** 흰 카드 + 큰 그림자 + 원근 기울기. 카드 안의 학생 이름·점수·수치는 모두 연출용 예시 데이터입니다.
- **엔딩 워드마크:** Gilroy ExtraBold. Gilroy는 유료 상업 폰트라 프로젝트에 포함하지 않았고, 라이선스 파일(이름에 "Gilroy"가 들어간 .otf/.ttf/.woff2)을 `public/fonts/`에 넣으면 자동으로 적용됩니다. 그 전까지는 모양이 가장 비슷한 무료 폰트 Plus Jakarta Sans ExtraBold(OFL)로 대체됩니다.

## 6. 사운드 — BGM + 효과음

모든 소리는 코드로 합성한 오리지널입니다(외부 샘플·음원 없음 → 라이선스 문제 없음). 효과음 105개는 `src/audio/cues.ts`의 큐 시트에 화면 이벤트 프레임 단위로 고정돼 있어서, 샷 타이밍을 바꾸고 `npm run audio`를 다시 돌리면 소리도 자동으로 다시 맞춰집니다.

**BGM (90 BPM, D단조 → D장조)**

| 구간 | 시간 | 음악 |
|---|---|---|
| 인트로 | 0–4.0초 | 시계 째깍(8분음표), 낮은 D 드론, Dm → B♭maj7 패드, 2.0초부터 베이스 펄스와 라이저 |
| 질문 | 4.0–5.3초 | S03 질문 동안 음악 전체가 화상회의 너머로 듣는 것처럼 먹먹해짐 |
| 브레이크 | 5.3–6.0초 | 음악이 멈추고, 거꾸로 재생한 D 화음이 히트로 빨려 들어감 (슬롯 롤 효과음만 남음) |
| 전환 | **6.0초** | ClassIn 슬롯 착지 = 브랜드 히트. 밝은 D장조로 전환 |
| 그루브 | 6.0–11.3초 | D – A – Bm – G, 기능 카드마다 코드가 바뀜. 벨 훅 멜로디 + 플럭 아르페지오 + 클랩 그루브 |
| 프리드롭 | 11.3–12.0초 | 스네어 롤 + 라이저, 마지막 반 박은 완전 무음 |
| 드롭 | **12.0초** | "AI" 슬램과 함께 일렉트로닉 드롭: 4/4 킥, 펌핑 패드, 16분 아르페지오 (Bm – G – D – A) |
| 업그레이드 | 16.0 / 16.67초 | v2.0 · v3.0 착지에 맞춰 A – C♯ – E 상행 벨 (A장조 화음 위) |
| 리와인드 | 17.3초 | 드롭을 테이프처럼 거꾸로 감아 콜백 문장으로 |
| 콜백 | 17.3–18.7초 | 부드러운 Dsus2 패드와 벨 몇 음, 조용하게 |
| 로고 | **18.67초** | 로고 히트 + D add9 화음이 마지막 프레임까지 울리고 잦아듦 |

**효과음 (47종, 105큐)**: 시계 롤링·째깍 가속, 잡무 알림 핑 10개(카드가 뜨는 위치대로 좌우 패닝), 늘어나는 막대 라이저, 회의 타일 도미노 클릭 9개, 펜 취소선, 슬롯 롤, 브랜드 히트, 카드 사이 휩, 녹화 셔터·체크, 보강 카드 비행·플립, 데이터 틱, 학생 그리드 팝 레인, AI 드롭·글리치, 스캔 스윕, HUD 타이핑, AI 정렬 스윕·체크·타이핑, 업그레이드 스텝·반짝이·배지, 리와인드, 로고 히트, CTA 클릭.

**믹스 스펙**: -14 LUFS (integrated), 트루 피크 -1.1 dBTP, 48 kHz 스테레오. 영상에서 화면 이벤트와 소리의 오차는 측정값 ±15 ms 이내(1프레임 = 33 ms).

**파일**
- `public/audio/soundtrack.wav`: 최종 믹스 (렌더 시 영상에 자동 포함)
- `out/stems/music.wav`, `out/stems/sfx.wav`: 편집용 스템 (`npm run audio`로 생성)

**다시 만들기**: 처음 한 번 `npm run audio:setup`(Python 가상환경) → `npm run audio` → `npm run render`

## 7. 확정 전에 확인할 것

1. **AI 기능 명칭과 범위:** "AI 강의평가" 리포트의 지표(발화 비율 · 질문 수 · 학생 참여 · 집중 구간, 레이더 5축), "AI 관리"의 할 일 정렬·요약, 업그레이드 장면의 "AI 평가" 점수와 피드백 문구가 실제 ClassIn 기능과 맞는지. 다르면 화면 요소를 실제 기능으로 바꿉니다.
2. **공식 로고 SVG와 브랜드 컬러:** 지금은 Pretendard로 쓴 "ClassIn" 텍스트와 랜딩 페이지의 그린입니다.
3. **CTA 문구와 URL**
4. **화면 비율:** 지금은 16:9. 인스타그램·쇼츠용 9:16이 필요하면 레이아웃을 따로 잡습니다.
5. **음원:** 지금 BGM은 코드로 합성한 오리지널입니다. 라이선스 음원으로 바꾸고 싶으면 90 BPM 곡을 고르거나, 곡의 BPM과 히트 위치에 맞춰 컷을 다시 맞춥니다.
